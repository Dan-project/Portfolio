# Portfolio — Dan Calamia

Site personnel présentant mon parcours d'ingénieur en robotique (Master Systèmes Avancés et Robotique, Sorbonne Université & ENSAM), mes projets académiques/personnels et mes expériences de stage.

Site statique (HTML / CSS / JS vanilla, sans dépendance de build) déployé via GitHub Pages.

## Structure

```
index.html              Page principale (une seule page, sections ancrées)
assets/css/style.css    Styles (thème sombre, animations)
assets/js/main.js       Interactions (particules, scroll-reveal, modales projets)
assets/img/             Visuels des projets (extraits du portfolio PDF)
assets/docs/            Portfolio PDF complet, téléchargeable depuis le site
```

## Déploiement

GitHub Pages sert directement la branche par défaut (`/` racine) — aucune étape de build nécessaire.
Pour l'activer : **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**.
